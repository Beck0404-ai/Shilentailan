Энэхүү репозиторид Монгол Улсын **Нийтийн мэдээллийн ил тод байдлын тухай хуулийн хүрээнд** байгууллагын нээлттэй мэдээллийг [https://www.shilen.gov.mn/](https://www.shilen.gov.mn/) цахим хуудасны **5 чиглэлийн 87 мэдээллээс байгууллагад хамааралтай 26 мэдээллийг** нийтлэн ажилласан он цагийн дараалал ба баталгаажуулсан зургууд бүхий албан тайлан, интерактив веб дэшборд багтсан болно.
